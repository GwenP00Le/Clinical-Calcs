3. Catch-Up Titrasi (Opsional)

Digunakan untuk menghitung penyesuaian laju tetesan jika resusitasi sedang berjalan atau pasien datang terlambat (sudah mendapat terapi cairan dari luar).

Durasi resusitasi berjalan: 0 jam

Target Seharusnya Skrg: 0 ml

4. Evaluasi Urine Output

Urine adalah indikator resusitasi terbaik. Target: Dewasa 0.5 ml/kg/jam, Anak 1 ml/kg/jam, Elektrik 1-1.5 ml/kg/jam (cegah mioglobinuria).
